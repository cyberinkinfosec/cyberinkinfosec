### 🕵️ About Me

I'm a security researcher with **2 years of hands-on experience** in penetration testing, with a strong pull toward the **offensive side** — black box engagements especially, where I get to think like an attacker with zero prior knowledge of the target.

My work spans authorized penetration tests and independent vulnerability research, followed through with responsible disclosure. A couple of things I've dug up along the way:

- 🔓 Found and responsibly disclosed a hardcoded bearer token with broken access control (OWASP A01:2021) and an unauthenticated endpoint leaking employee PII on a production web application — both remediated after report.
- 🔗 Uncovered a critical vulnerability chain during an authorized pentest — backend framework fingerprinting → exposed diagnostic endpoint → extraction of JWT tokens, AWS credentials, and in-memory secrets — reported and fixed.

I build my scripting and automation with Python, JavaScript, and HTML — often leaning on AI tools to move faster while I learn.

- 🎯 Currently sharpening: black box methodology, web app exploitation, recon automation
- 🌱 Learning: scripting my own recon/exploitation tooling
- 💬 Ask me about: pentesting, vulnerability disclosure, offensive security
- ⚡ Fun fact: I'd rather break something than be told how it works
