questions

FAQ

Do you only do black box testing?

Black box is our default and our strongest suit, since it mirrors how a real attacker approaches a target with no inside knowledge. Grey box and white box engagements are available too, depending on what you need covered.

How is AI/LLM security testing different from a normal pentest?

Traditional pentesting targets infrastructure and application logic. AI security testing also covers prompt injection, jailbreaks, unsafe tool use by agents, and data leakage through retrieval pipelines — failure modes that don't exist in a typical web app.

Will you retest after we fix an issue?

Yes. Remediation retesting is included so you get confirmation the fix actually closed the issue, not just a report telling you what was wrong.

Do you sign NDAs before scoping?

Yes — every engagement starts with a signed authorization and NDA before any testing begins.
